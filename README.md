# سِمة | SIMA

منصة سودانية للخدمات والإعلانات، بهوية سودانية بروح عالمية.

## تعريف المشروع

تهدف **سِمة (SIMA)** إلى جمع إعلانات الخدمات والاحتياجات المحلية في منصة واحدة، مع قابلية التوسع لتغطية ولايات ومدن السودان.

## القرارات المعتمدة

- **الاسم التجاري:** سِمة | SIMA.
- **السوق المستهدف:** السودان بالكامل.
- **رسوم الإعلان:** 20,000 جنيه سوداني.
- **طريقة الدفع عند الإطلاق:** التحويل عبر بنكك.
- **أرقام الهاتف:** دعم الأرقام السودانية المحلية دون اشتراط كتابة مفتاح الدولة.
- **المدن والأحياء:** تجهيز بيانات المدن والأحياء، مع تفعيل المدن المطلوبة من لوحة الإدارة فقط.
- **الهوية البصرية:** سودانية بروح عالمية، مع استلهام بصري من أهرامات البجراوية، وشلالات السبلوقة، وسكة حديد عطبرة، وعلم السودان.

## مبدأ الاستقلال

هذا المستودع مخصص لنسخة **SIMA-SUDAN** فقط. يجب أن تبقى النسخة السعودية من دليلك مستقلة تماماً، وألا تُجرى عليها أي تعديلات أثناء تطوير سِمة.

يلزم فصل بيئة التشغيل وقاعدة البيانات وحسابات الإدارة ومفاتيح الاتصال والتخزين وإعدادات النشر الخاصة بسِمة عن أي مشروع آخر. يمنع تضمين كلمات المرور أو مفاتيح الخدمات أو بيانات الحسابات البنكية السرية في ملفات المستودع العامة.
